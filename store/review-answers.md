# Ответы для проверки Chrome Web Store

Материал для полей «Обоснование разрешений» и «Практики конфиденциальности» в кабинете разработчика. Формулировки
проверены на соответствие фактическому поведению кода: ничего лишнего не заявляем.

## Назначение расширения (single purpose)

Расширение решает одну задачу: составить черновик сопроводительного письма под конкретную вакансию на hh.ru на основе
резюме пользователя и вставить этот текст в форму отклика. Никаких других функций нет.

## Обоснование разрешений

| Разрешение | Обоснование для проверяющего |
| --- | --- |
| `storage` | Локальное хранение настроек пользователя: API-ключ, текст резюме, выбранный провайдер и стиль письма. Данные не покидают профиль браузера. |
| `activeTab` | Доступ к текущей вкладке возникает только по явному действию пользователя: нажатие кнопки в popup, кнопка на странице или горячая клавиша `Alt+Shift+C`. |
| `scripting` | Единичное чтение текста резюме со страницы hh.ru при нажатии кнопки «Загрузить резюме», чтобы не заставлять пользователя копировать текст вручную. |
| `https://hh.ru/*`, `https://*.hh.ru/*` | Чтение текста вакансии со страницы и вставка готового письма в поле сопроводительного письма формы отклика. |
| `https://api.deepseek.com/*`, `https://api.openai.com/*`, `https://openrouter.ai/*`, `https://api.groq.com/*`, `https://api.mistral.ai/*`, `https://generativelanguage.googleapis.com/*` | Отправка запроса на генерацию текста тому провайдеру языковой модели, которого пользователь выбрал в настройках. Список отражает поддерживаемые сервисы. |
| `http://localhost/*`, `http://127.0.0.1/*` | Поддержка локальных моделей (Ollama, LM Studio): в этом режиме данные не покидают компьютер пользователя. |
| `optional_host_permissions: https://*/*` | Пользователь может указать адрес собственного OpenAI-совместимого сервера. Такой адрес заранее неизвестен, поэтому разрешение запрашивается в рантайме кнопкой «Разрешить доступ к домену» и относится только к указанному домену. Отзывается в `chrome://extensions`. |

## Удалённый код

Расширение не загружает и не исполняет удалённый код: все скрипты поставляются внутри пакета, `eval` не используется,
внешних скриптов нет. Сетевые запросы — только к API языковых моделей и только за текстом ответа.

## Практики конфиденциальности: предлагаемые ответы

Форма в кабинете меняется, поэтому сверьте формулировки с актуальным списком категорий. По факту расширение
обрабатывает следующее:

| Категория | Обрабатывается | Пояснение |
| --- | --- | --- |
| Authentication information (данные аутентификации) | Да | API-ключ провайдера, введённый пользователем. Хранится локально, передаётся только владельцу ключа. |
| Personal communications (личные материалы) | Да | Текст резюме и сопроводительного письма, то есть материалы, созданные пользователем. |
| Website content (содержимое сайта) | Да | Текст страницы вакансии hh.ru, который пользователь открыл. |
| Personally identifiable information | Нет | Почта, имя, адрес, телефон не собираются и не хранятся отдельно; контакты могут быть в тексте резюме, который пользователь вставил сам. |
| Health, financial, location, web history, user activity | Нет | Не запрашиваются и не читаются. |

Дополнительные утверждения, которые можно отметить:

- Данные **не продаются** третьим лицам.
- Данные **не передаются** никому, кроме выбранного пользователем провайдера языковой модели.
- Данные **не используются** для оценки платёжеспособности и для целей, не связанных с единственной функцией расширения.
- Разработчик не имеет собственного сервера и не получает пользовательские данные.
- Ссылка на политику конфиденциальности: [PRIVACY.md](../PRIVACY.md) (опубликуйте её по публичному URL, например
  через GitHub Pages или ссылкой на файл в репозитории).

## Что важно не забыть при подаче

- **Поле `key` из манифеста удалено в релизной сборке.** Публичный ключ в исходном манифесте нужен только для
  стабильного идентификатора локальной копии; в стор он не идёт, иначе идентификатор не совпадёт с выданным Google.
  Скрипт `package.ps1` вырезает это поле автоматически.
- Расширение не отправляет отклики и не совершает действий от имени пользователя — это стоит подчеркнуть, если
  проверяющий спросит про автоматизацию hh.ru.
- Скриншоты и иконка должны соответствовать фактическому интерфейсу: витрина с самодельными макетами — частая причина
  отказа.
